# Hinglish Smart Writing Assistant

A Hinglish writing assistant that converts Roman-script Hinglish into native Hindi script, optionally improves phrasing, and can translate the result into English.

## Features
- Roman Hinglish to Hindi-script transliteration
- Optional phrasing improvement
- Optional English translation
- Configurable handling of English words
- Gradio user interface
- Evaluation using character-level, word-level, and translation-quality metrics

## Setup
1. Clone this repository:
   ```bash
   git clone <YOUR_GITHUB_REPOSITORY_URL>
   cd <YOUR_REPOSITORY_FOLDER>
   ```
2. Create and activate a Python virtual environment (recommended).
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Open `Hinglish_Assistant.ipynb` in Jupyter or Google Colab and run the cells in order.

Some model checkpoints may require internet access, authentication, or additional setup. Follow the instructions in the notebook.
